# Security

## Reporting a security problem

Please email team@digitalhabits.org rather than opening a public issue. Describe the issue, how to reproduce it, and which version of Digital Habits: Blocker you use and on which platform, and send us the diagnostics report (Settings → Diagnostics → Copy to Clipboard). We reply within three days, treat security problems as our top priority, and let you know when a fix is released.

If you use the Digital Habits: Focus browser extension for website blocking and the problem involves it, report it in the same way in the same email.

## Anything else

Either reach out at team@digitalhabits.org or open an issue at <https://github.com/digitalhabits/dh-blocker/issues>.
